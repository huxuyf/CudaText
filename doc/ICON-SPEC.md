# CudaText 图标规范

适用目录：`data/sideicons/`、`data/toolbaricons/`
两处共用同一套几何语言，仅按尺寸分档，不混用风格。

---

## 1. 几何规范

| 项 | 值 | 说明 |
|---|---|---|
| 设计网格 | 24 × 24 | 所有路径在此网格上定义，再按目标尺寸缩放 |
| 内容区 | 3 – 21（18 × 18） | 四周各留 3 单位，占 75% |
| 描边宽度 | 2 px（落盘值） | 不受尺寸影响，20/24 均为 2px |
| 端点 | 圆头（round cap） | 所有线段端点、折线拐角均为圆角 |
| 圆角 | 小控件 2.5、大容器 3.5（网格单位） | 同层级保持一致 |
| 最小间距 | 2 单位 | 笔画之间不得小于此值 |
| 填充 | 无 | 仅 `tree` 的节点、`opt` 的滑块圆为实心点 |

### 尺寸与线宽补偿

线宽在落盘时恒为 2px，因此网格单位线宽随目标尺寸变化：

| 目标 | 画布 | 网格单位线宽 | 缩放比 |
|---|---|---|---|
| 20 × 20（侧栏） | 160 | 2.40 | 8:1 |
| 24 × 24（工具栏） | 192 | 2.00 | 8:1 |

画布固定为目标尺寸的 8 倍，用整数比下采样（BOX），避免 LANCZOS 振铃在浅色图标边缘产生白光晕。

## 2. 颜色与背景

| 目录 | 前景色（PNG 实测） | 适用背景 |
|---|---|---|
| `sideicons/common_20x20` | `#E5E5E5` | 深色侧栏（`SideBg` 较暗） |
| `sideicons/octicons_20x20` | `#000000` | 亮色侧栏 |
| `toolbaricons/default_24x24` | `#555753` | 亮色工具栏 |
| `toolbaricons/light_24x24` | `#C6CAC1` | 深色工具栏 |

侧栏图标相对本仓库各上游主题 `SideBg` 的实测对比度：`common_20x20` 在深色主题为
6.95–14.29:1，`octicons_20x20` 在浅色主题为 2.23–5.27:1（最低为 navy 的 `#404080`）。
工具栏底色随控件主题变化，本仓库主题文件未定义该色值，因此不给出固定对比度数值。

图标本身不带主题色。切换主题时需同步切换对应的图标目录，否则会出现"浅色图标配亮背景"看不见的情况：

```jsonc
// settings/user.json
"ui_sidebar_theme": "octicons_20x20",   // 亮色主题（如 syn / green / navy）
"ui_sidebar_theme": "common_20x20",     // 深色主题（如 ebony / sub / monokai_pro）
"ui_toolbar_theme": "default_24x24",    // 亮色主题
"ui_toolbar_theme": "light_24x24",      // 深色主题
```

## 3. 语义映射

### 侧栏（20 × 20）

| 文件 | 含义 | 图形 |
|---|---|---|
| `console` | 控制台 | 圆角窗 + `>` 提示符 + 光标线 |
| `find` | 查找 | 放大镜 |
| `font` | 字体设置 | 字母 A |
| `menu` | 菜单 | 三条等高横线 |
| `output` | 输出面板 | 圆角窗 + 两条文本行 |
| `project` | 项目 | 等距立方体 |
| `snip` | 代码片段 | 圆角框 + 两条片段线 |
| `tabs` | 标签页列表 | 前后叠放的两个页签 |
| `tree` | 代码树 | 竖干 + 两条分支 + 实心节点 |
| `validate` | 校验 | 对勾 |

`common_20x20` 与 `octicons_20x20` 各含 12 个 PNG：上表为 10 个在用语义，另有
`ftp.png`、`ftp log.png`，在本仓库代码中无引用。

### 工具栏（24 × 24）

| 文件 | 含义 | 图形 |
|---|---|---|
| `case` | 大小写切换 | `Aa` |
| `comment` | 切换注释 | `//` 双斜线 |
| `e_copy` | 复制 | 前后两个圆角矩形 |
| `e_cut` | 剪切 | 剪刀 |
| `e_paste` | 粘贴 | 剪贴板 + 夹子 |
| `e_undo` | 撤销 | 左指箭头 + 回卷弧 |
| `e_redo` | 重做 | 右指箭头 + 回卷弧 |
| `f_new` | 新建 | 文档 + 折角 |
| `f_open` | 打开 | 文件夹 |
| `f_save` | 保存 | 托盘 + 向下箭头 |
| `indent` | 增加缩进 | 左侧竖线 + 右箭头 + 三条文本行 |
| `unindent` | 减少缩进 | 左侧竖线 + 左箭头 + 三条文本行 |
| `map` | 小地图 | 圆角框 + 缩略文本 + 视口竖线 |
| `opt` | 选项设置 | 三条滑块 + 圆形手柄 |
| `unpri` | 不可打印字符 | 段落标记 ¶ |

同一语义在两处使用同一图形语言：侧栏与工具栏不重复出现同一操作；`tree` 与 `indent` 都用"竖线 + 分支"，但节点形态不同（实心点 vs 箭头），避免混淆。

### 修复的旧问题

| 问题 | 说明 |
|---|---|
| 风格混用 | `common` 为实心粗笔画，`octicons` 为 GitHub 细线，两者切换时观感断裂 |
| 线宽不一 | 同一目录内 `tree.png` 96 个完全不透明像素、`menu.png` 12 个，笔画粗细差异明显 |
| 语义重复 | `e_copy` 与 `snip` 都是"方框套方框"，靠猜区分 |
| 小尺寸糊化 | 旧 20px 图标部分元素（如树节点）小于线宽，缩放后消失 |

## 5. 新增图标的做法

1. 在 24 网格上画，内容区 3–21，描边按 2px 设计
2. 端点、拐角用圆头
3. 单一图形语言：线性为主，仅必要的节点可实心
4. 生成 20px 时不要手工缩放位图，按第 1 节的线宽补偿重新渲染
5. 四个目录都要出图，缺一个就会在该主题下回退到旧图标
