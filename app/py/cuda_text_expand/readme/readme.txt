文本展开 (cuda_text_expand)
===========================

功能
----
在文本区输入触发词后按空格，自动替换为配置文件中对应的文本。
例如配置 sa=select * from，输入 sa 再按空格，得到 select * from 。

配置文件
--------
默认位置：插件目录下的 config.txt。
可通过菜单「文本展开 → 选择配置文件...」指定其他 txt 文件；
选择的路径保存在 settings/plugins.ini 的 [cuda_text_expand] 段。

格式：每行一条，以第一个等号分割。
    触发词=替换文本

示例：
    sa=select * from
    w=where
    ord=order by

规则说明
--------
- 空行、以 # 开头的行会被忽略。
- 触发词两侧的空白会被去除；替换文本保持原样（行尾换行除外）。
- 同一触发词重复出现时，以最后一行为准。
- 触发词建议由字母、数字、下划线组成。
- 匹配时从光标向前扫描，遇到空白、标点或符号即停止，
  因此 (sa、,sa、。sa 等写法都能命中 sa。
- 替换后会自动补一个空格；若替换文本已以空格或制表符结尾，则不再补。
- 触发词中含中文字符时不展开，避免中文输入法选词时误触发。
- 按空格前若存在选区或多光标，不处理。
- 配置文件修改后无需重启，下次按空格时自动重新加载。

菜单
----
文本展开 → 选择配置文件...
文本展开 → 打开配置文件
文本展开 → 重新加载配置
文本展开 → 帮助
